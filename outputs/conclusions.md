Exploratory Data Analysis & Preprocessing Summary — Palmer Penguins DatasetExploratory Data Analysis (EDA) and data preprocessing were performed on the Palmer Penguins dataset to examine feature distributions, resolve data-quality issues, and produce a clean, machine-learning-ready dataset. Initial inspection revealed 344 biological records across three penguin species (Adelie, Chinstrap, and Gentoo) and three islands (Biscoe, Dream, Torgersen), combining continuous morphological measurements (bill_length_mm, bill_depth_mm, flipper_length_mm, body_mass_g) with categorical attributes (species, island, sex). Summary statistics and null checks immediately revealed incomplete entries—two records lacked physical measurements and roughly 10–11 entries were missing values in sex—while duplicate checks confirmed zero exact duplicate rows.   To preserve all 344 observations without introducing bias, missing numerical values were imputed using column medians rather than means so multi-species size differences and skewed distributions would not distort central tendency estimates. Missing categorical values in sex were imputed using the mode, maintaining sample completeness for discrete labels. String trimming, title-case normalization, and placeholder cleanup verified consistent categorical formatting across all text columns. Outlier analysis using boxplots and the $1.5 \times \text{IQR}$ rule showed that upper-end measurements—most notably higher body mass among Gentoo penguins—represent genuine biological variation across species rather than measurement errors, justifying full data retention.   Visual exploration provided key structural insights for downstream modeling. Histograms and species-grouped boxplots showed bimodal flipper-length distributions and clear body-mass separation between Gentoo and smaller species (Adelie and Chinstrap), while bar charts highlighted moderate class imbalance across species. Correlation heatmaps revealed a strong positive relationship between flipper length and body mass ($r \approx 0.87$) alongside distinct bill-proportion patterns across species. Guided by these findings, a bill_length_depth_ratio feature was engineered to capture proportional bill geometry independent of overall body size. Finally, categorical predictors were transformed using binary Label Encoding for sex and One-Hot Encoding for the nominal island feature (leaving the target species intact), and continuous features were standardized via StandardScaler so all predictors share comparable scale. Final verification confirmed zero missing values and zero duplicates, yielding a verified, ML-ready dataset saved as penguins_cleaned.csv.
